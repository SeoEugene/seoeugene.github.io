# 서유진 개발 포트폴리오

**https://seoeugene.github.io**

3년 차 개발자 서유진의 포트폴리오 사이트입니다. Vue 프론트엔드로 시작해, 국가 R&D 에너지 거래 플랫폼의 풀스택 운영을 거쳐, 지금은 LLM 에이전트가 사내 시스템을 안전하게 쓰도록 MCP 서버와 RPA 수집 파이프라인을 만들고 있습니다.

## 담긴 내용
- **Cover letter · Resume**: 소개, 경력, 학력, 교육, 자격증, 기술
- **Project**: 실무 프로젝트 4개의 서비스 기능, 시스템 아키텍처, 기술 스택, 해결한 문제
- **Education**: 학교와 교육기관에서 만든 프로젝트와 학습 기록

## 만든 방식

- 아키텍처 다이어그램은 인라인 SVG로 직접 그림
- GitHub Pages로 배포
