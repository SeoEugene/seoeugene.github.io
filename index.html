해결한 문제Problems

LLM이 질문에 다른 사람의 사번을 넣으면 남의 매출을 볼 수 있다

사번을 도구 입력에서 받지 않고, 검증된 토큰에서만 꺼내도록 설계했습니다.

연결 시점이 아니라 도구를 부를 때마다 JWT를 검증하도록 바꿨습니다.

고객사 Windows 서버가 방화벽 안에 있어 직접 호출할 수 없다

Agent가 Worker에서 작업을 가져가 실행하고 결과를 올리는 polling 방식을 만들었습니다.
